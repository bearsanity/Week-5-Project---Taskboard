# Week-5-Project---Taskboard

## Description

This project was built to strengthen my understanding of using JavaScript to dynamically generate UI elements, manage application state, and create interactive features like drag-and-drop. I learned how to organize data using objects and arrays, persist tasks with localStorage, and update the DOM in response to user actions such as adding, deleting, and moving tasks between columns. I also gained experience integrating external libraries like jQuery UI and Day.js to handle draggable cards and date logic.

## Usage

Enter a task from the top right of the page. Once created, the tasks can be dragged and dropped between columns.
